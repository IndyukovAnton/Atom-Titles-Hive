Улучшения вокруг AI, удобства библиотеки и стабильности. Релиз **0.4.0**.

## Codex CLI

- Третий источник AI-рекомендаций: **Codex (Local CLI)** рядом с Claude API и Claude CLI.
- В настройках — живой статус CLI, выбор модели и путь к бинарнику.
- Карточки стримятся так же, как у Claude: прогресс, обоснования, бейдж источника.

## Дерево групп

- Группы теперь образуют **дерево**: вложенность, перетаскивание и сохранение порядка.
- Порядок (`sortOrder`) хранится на сервере — раскладка не сбрасывается после перезапуска.
- Старый одноуровневый DnD заменён на headless-tree с предсказуемым UX.

## Настройки → Провайдеры

- Отдельный таб **«Провайдеры»** для ключей внешних сервисов.
- Бывший AI-таб переименован в **«Интеграции & AI»**.
- На AI-карточках появился **бейдж источника** (Claude / Codex и т.д.).

## Регистрация без email

- Email при регистрации **необязателен** — можно завести аккаунт только с логином и паролем.
- Уже созданные профили с email работают как раньше.

## Навигация

- На подстраницах (профиль, настройки, уровни, история версий) — панель **SubPageNav** вместо одиночной кнопки «Назад».
- Быстрые переходы между разделами с подсветкой активного.

## Безопасность и стабильность

- **Rate limiting** на API — защита от случайных и злонамеренных всплесков запросов.
- **SSRF-защита** при скачивании обложек по URL.
- Backend стартует без гонки порта: порт публикуется только после готовности сервиса.

## Страница обновлений

- Интерфейс стал **компактнее**: список версий слева, детали выбранной — справа.
- Данные по-прежнему берутся из markdown-файлов — добавить релиз = положить новый `.md`.
