Патч: установщик корректно завершает старый backend-процесс перед заменой файлов.

## Исправлено

- **Обновление приложения**: в 0.4.2 хук установщика искал backend под неверным именем файла и не срабатывал — процессы продолжали блокировать замену `backend.exe`. Теперь установщик сначала завершает само приложение, затем фоновые backend-процессы по точному пути в каталоге установки и дожидается освобождения файла.
- Зависшие процессы backend от прошлых неудачных попыток обновления будут автоматически завершены при установке этой версии — библиотека и база данных не пострадают.
