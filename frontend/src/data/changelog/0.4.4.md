Технический патч: sidecar гарантированно умирает вместе с приложением.

## Исправлено

- **Сироты backend.exe**: раньше при аварийном выходе или авто-обновлении процесс backend мог остаться жить и блокировать файлы установки. Теперь sidecar (и его потомки — CLI-агенты) обёрнут в Windows Job Object с `KILL_ON_JOB_CLOSE` — ОС сама убивает всё дерево при любой смерти приложения.
